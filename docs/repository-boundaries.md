# FE · BE · AI 저장소 책임

## FE

- 화면, 스타일, 브라우저 동작을 관리합니다.
- BE API로 로그인, 공지, 추천, 저장 기능을 사용합니다.
- API 키, 내부 AI 토큰, DB 접속정보를 보관하지 않습니다.
- 브라우저가 AI 서비스에 직접 요청하지 않습니다.

## BE

- FastAPI 웹 앱의 사용자 진입점은 포트 8000입니다.
- 로그인·계정 권한을 확인하고 학교별 공지 데이터를 보호합니다.
- PostgreSQL, 공지 수집, 태깅, 검색, 추천, 저장 상태를 관리합니다.
- 챗봇 질문에 대해 허용된 공지 근거를 선별하고 AI에 전달합니다.
- 생성형 답변·요약·selector 제안은 AI 서비스를 호출합니다. BE는 프롬프트 및 provider SDK를 소유하지 않습니다.
- AI 응답을 화면 계약에 맞게 돌려주고 selector 후보는 로컬 파서로 검증합니다.

## AI

- BE가 전달한 근거를 사용해 답변과 생성형 요약을 만듭니다.
- 공지 HTML에서 selector 후보를 제안합니다. 결과의 실제 유효성은 BE가 확인합니다.
- 모델 provider 및 API 키 설정을 소유합니다. 키는 AI 서비스 환경변수에만 저장합니다.
- 계정 인증, DB 접근, 공지 검색/권한 판단, 크롤링은 하지 않습니다.

## 서비스 연결

1. 브라우저는 BE 웹 앱 `http://localhost:8000`만 사용합니다.
2. BE가 사용자를 인증하고 학교/공지 접근을 확인합니다.
3. BE는 필요한 근거만 내부 인증 헤더와 함께 AI 서비스에 보냅니다.
4. AI 서비스는 로컬 기본 포트 8001 또는 배포된 `AI_SERVICE_URL`에서 응답합니다.
5. `AI_SERVICE_TOKEN`은 BE와 AI에서 동일하게 설정하며 브라우저에 보내지 않습니다.

세부 실행 절차는 각 저장소의 `HANDOFF.md`를 참고합니다. FE 변경은 BE 통합 앱의 템플릿/정적 파일 복사본과 동기화해야 합니다.
